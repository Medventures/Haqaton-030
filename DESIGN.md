# AqylRoute UI · рабочий дизайн-код

Статус: черновик для выбора палитры и библиотеки компонентов. Основной экран — кабинет родителя в `/parent`.

## Принципы

- Спокойная светлая основа. Цвет помогает заметить действие или срок, а не заполняет весь экран.
- Одна шкала отступов и одинаковые элементы на всех экранах родителя.
- Статус всегда подписан текстом. Цвет один не передаёт смысл.
- Синтетические данные отмечаются на экране. Макетные действия не выглядят рабочими.

## Форма и ритм

- Шрифт: Geist с кириллицей; запасной — Arial.
- Основной текст: 12–14 px; заголовок страницы: 26–34 px.
- Радиусы: 8 px для кнопки, 13 px для вложенной карточки, 18 px для панели.
- Отступы: базовый шаг 4 px; основные интервалы 8, 12, 16, 24, 32 px.
- Тень почти незаметная. Состояние карточки в первую очередь задаёт граница.
- Фон страницы: ровный тёплый серо-зелёный тон и очень слабое светлое пятно в углу. Никаких фотографий и сильных градиентов в рабочих таблицах.

## Общие компоненты

`src/components/navbar.tsx` содержит верхний navbar кабинета родителя и выход. Маршрут и визуализация агента используют готовые Card, Badge и Button из shadcn/ui. Новые статусы нужно подписывать текстом.

Следующие общие элементы: Input, Select, Dialog, Table, Tabs, Toast. Состояния для каждого: default, hover, focus, disabled, loading и error, где они применимы. Реальные действия агента будут подключаться к серверной логике отдельно от демо-макета.

## Выбор библиотеки

| Вариант | Подходит, когда | Цена выбора |
| --- | --- | --- |
| shadcn/ui | Нужен полный контроль над видом и кодом компонентов; текущий стек Tailwind 4 уже есть | Компоненты копируются в репозиторий, их обновления ведёт команда |
| Mantine | Нужны много готовых форм и виджетов с быстрым стартом | Отдельная система стилей и тема поверх нынешнего Tailwind |
| MUI | Нужен широкий набор зрелых компонентов и развитые таблицы | Более заметный Material-стиль и настройка SSR/темы для Next.js |

Для текущего макета используется **shadcn/ui** поверх Tailwind 4.
