## Purpose & Scope

Контракт текущего интервью в кабинете родителя. Эталон текстов: @.archcore/parent-interview-question-bank.doc.md. Код: @src/lib/interview.ts, @src/app/parent/interview/interview.tsx, @src/app/parent/interview/actions.ts.

## Surface

- Экран @src/app/parent/page.tsx показывает один из десяти последовательных вопросов.
- Ответы хранятся в `public.interview_sessions.answers_json` по `parent_id`.
- Статусы сеанса: `draft`, `completed`.
- Миграции и RLS: @supabase/migrations/0002_interview_sessions.sql, @supabase/migrations/0003_cases_plans_catalog.sql и @supabase/migrations/0004_parent_interview.sql. Миграция 0003 добавила в `interview_sessions` поля `case_id`, `revision`, `question_bank_version`, `question_history_json`; текущий интерфейс их не использует. Поле `profiles.role` остаётся для схемы кейсов; текущий интерфейс показывает только родительский поток.
- Список услуг для вопроса 9: `services` в @src/lib/interview.ts. Это варианты ответа, не подтверждение доступности услуги.

## Normative Behavior

1. WHEN родитель открывает кабинет без сохранённых ответов, the интерфейс MUST открыть первый вопрос без ответа (в демо — вопрос 9).
2. WHEN родитель открывает кабинет, the интерфейс MUST предзаполнить на клиенте ответы на вопросы 1–8 (`demoAnswers`); вопросы 9 и 10 родитель заполняет сам.
3. WHEN родитель сохраняет шаг, the сервер MUST проверить каждый присланный ответ по идентификатору вопроса.
4. WHEN ответы проходят проверку, the сервер MUST сохранить в Supabase ответ текущего шага вместе со всеми предыдущими, включая предзаполненные.
5. WHEN родитель открывает кабинет повторно, the интерфейс MUST восстановить ответы и прогресс.
6. WHEN родитель отвечает на вопрос 9, the интерфейс MUST предлагать только варианты локального списка услуг.
7. WHEN родитель завершает десять вопросов, the сервер MUST установить `status = completed`.
8. WHEN интервью завершено, the интерфейс MUST показать сообщение о сохранённых ответах без ожидания куратора.
9. WHEN родитель меняет ответ после завершения, the сервер MUST вернуть статус `draft`.
10. WHEN другой пользователь запрашивает ответы родителя, the RLS MUST запретить доступ.

## Constraints & Invariants

- Демо-значения не записываются в Supabase до первого сохранения шага; сохранённые ответы имеют приоритет.
- Пока интервью не завершено, опрос стоит в правой панели кабинета вместо агента (@.archcore/agent-timeline-demo.spec.md).
- Интервью не спрашивает диагноз, ИИН, ФИО ребёнка или документы.
- Завершение интервью пока не создаёт Case Plan. Демо-маршрут читает возраст и город для контекста, а ответ `COMPLETED_STAGES` — только как неподтверждённое сообщение семьи. До завершения интервью маршрут не показывает прогресс и пройденные этапы.
- Десять фиксированных вопросов удовлетворяют числовому диапазону 8–12, но адаптивность ещё не реализована. Банк вопросов v1 с ветвлением реализован в @src/domain/interview/bank.ts, но к интерфейсу не подключён.

## Failure Behavior

1. IF ответ не проходит проверку, THEN the интерфейс MUST оставить текущий шаг и показать ошибку.
2. IF Supabase не сохраняет ответ, THEN the интерфейс MUST оставить текущий шаг и показать ошибку.
3. IF один из десяти ответов отсутствует, THEN the сервер MUST отклонить завершение.

## Conformance

Пройти десять вопросов, перезагрузить кабинет после промежуточного шага, вернуться назад, завершить опрос. Убедиться, что сообщение о кураторе не появляется и ответы восстановлены из Supabase.
