## Findings

### Концепция «Дети Казахстана» 2026–2030

1. По материалу, Концепция предусматривает межведомственный цифровой инструмент для систематизации услуг и мер поддержки детям. Не проверено по первичному источнику.
2. По материалу, в инструмент интегрируют модуль маршрута сопровождения ребёнка на базе eGov. Срок по плану — декабрь 2026 года. Не проверено по первичному источнику.
3. По материалу, в Концепции используется логика «одного окна» и сопровождения ребёнка на всём жизненном пути. Не проверено по первичному источнику.
4. Вывод автора о позиционировании: совпадение с Концепцией подтверждает проблему, но создаёт риск. AqylRoute не подавать как каталог госуслуг или замену eGov. Тезис автора: AI-навигатор и case-management слой, который превращает правила трёх ведомств в подтверждённый человеком Case Plan и контролирует исполнение.

### Закон об ИИ и Цифровой кодекс

5. По материалу, закон «Об искусственном интеллекте» закрепляет принципы прозрачности, объяснимости, ответственности, подконтрольности и сохранения свободы решения человека. Не проверено по первичному источнику.
6. По материалу, Цифровой кодекс вступил в силу 12 июля 2026 года и предусматривает права человека при использовании алгоритмических и полностью автоматизированных решений. Не проверено по первичному источнику.
7. Соотнесение автора: обязательное подтверждение плана куратором отвечает принципам подконтрольности и свободы решения человека. Это интерпретация автора, юридической оценки нет.

### Персональные данные и медицинская тайна

8. По материалу, закон о персональных данных требует согласия субъекта или законного представителя на сбор и обработку. Не проверено по первичному источнику.
9. По материалу, согласие содержит перечень данных, срок обработки, сведения о передаче третьим лицам и о трансграничной передаче. Не проверено по первичному источнику.
10. По материалу, медицинские данные, факт обращения за медпомощью, сведения о состоянии здоровья и диагноз относятся к тайне медицинского работника. Не проверено по первичному источнику.
11. По материалу, при обработке реальных данных детей через внешние облачные сервисы потребуется отдельная юридическая и информационно-безопасностная проработка: основания обработки и трансграничная передача. Не проверено по первичному источнику.

### Что это значит для MVP (проектные предложения автора)

12. Публичная ссылка не означает публичные данные. Демо: синтетические маршруты `/demo/parent/case-a`, `/demo/curator/case-a`, `/demo/parent/case-b`, `/demo/curator/case-b`. Реальный режим: лендинг, вход, рабочее пространство родителя или куратора.
13. MVP не принимает ИИН, ФИО ребёнка, фотографии документов и медицинские выписки.
14. В OpenAI уходит обезличенный контекст: возрастная полоса (`age_band`), код региона, образовательная ступень, флаги `has_pmpk` и `receives_school_support`, цели родителя. Не уходят ФИО, ИИН, адрес, номер школы, диагноз, медкарта, скан заключения.
15. Для демо автор предлагает read-only синтетический маршрут, который не обращается к персональным таблицам.

### Технические источники (пересказ автора, документация не открывалась)

16. OpenAI Structured Outputs: строгая JSON Schema обеспечивает соответствие вывода схеме. Документация, по словам автора, отмечает, что структура не устраняет содержательные ошибки внутри корректного JSON. Следствие в материале: модель возвращает только `{action_id, priority, rationale}`, остальное достраивает backend из каталога. Структурные выводы рекомендованы вместо старого JSON mode.
17. Supabase: Auth связывается с Postgres Row Level Security. Документация, по словам автора, рекомендует RLS и защиту таблиц, доступных из клиента. Ключ service role обходит RLS и хранится только на сервере.
18. Next.js App Router: Server Components оставляют получение защищённых данных на сервере, Client Components обслуживают интерактив интервью и статусов. Route Handlers позволяют заменить отдельный backend.
19. FastAPI и Pydantic: валидация моделей запросов и фильтрация response models как второй слой типизации. Автор приводит довод: FastAPI выбран не из-за ограничений Node.js, а ради отдельного слоя оркестрации, понятного жюри.

## Synthesis

Материал строит позиционирование на совпадении с государственным направлением: цифровой маршрут ребёнка уже запланирован в Концепции на декабрь 2026, поэтому AqylRoute показывается как слой навигации и ведения случая, а не как каталог. Это проектный тезис автора, не проверенный по Концепции.

Правовые утверждения материала ведут к трём ограничениям MVP: человек подтверждает план, система не ставит диагноз, реальные чувствительные данные не принимаются. Главная мера по данным: обезличенный контекст для внешней модели и синтетические кейсы в публичном демо. Автор сам отмечает, что для реальных данных нужна отдельная проработка.

Технические источники в материале нужны для одного тезиса: корректная по схеме выдача модели не гарантирует верное содержание, поэтому нормативные поля берёт каталог, а допустимость действий проверяет сервер.

- Сверить технические утверждения с текущей документацией OpenAI, Supabase, Next.js, FastAPI.
