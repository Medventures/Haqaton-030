## Context
Спецификация @.archcore/document-intake.spec.md требует принимать заключение ПМПК, читать его моделью и применять к маршруту только после проверки родителем. @.archcore/personal-data-and-access.rnd.md принимает границу «только синтетические данные в MVP» и оставляет решение о реальных документах открытым. Заключение ребёнка — медицинские данные; часть реквизитов (ФИО, ИИН) может быть скрыта.
Юридические утверждения о персональных данных и трансграничной передаче в проекте не проверялись.

## Decision
- Оригинал хранится в закрытом Supabase Storage bucket `pmpk-documents`, путь `{parent_id}/{document_id}`; в таблице `pmpk_documents` хранится путь, не публичный адрес. Просмотр — по короткоживущей подписанной ссылке.
- Файл уходит в OpenAI только после явного согласия родителя в интерфейсе (версия текста согласия сохраняется: `PMPK_CONSENT_VERSION`) и с `store: false`, содержимым запроса.
- Модель извлекает поля и цитаты; полный текст и диагноз не сохраняются. Значения без цитаты сервер очищает.
- Загрузка идёт из браузера напрямую в Storage (политика RLS допускает загрузку только в путь зарегистрированного документа, ожидающего файл); записи в базу — через RPC service_role.
- Очистка: долг на удаление объектов записывается в `storage_deletion_queue` в транзакции с удалением строк; сервер удаляет объекты и подтверждает успех только после этого.

## Alternatives Considered
- Загрузка через функцию API: отклонена, лимит тела запроса на Vercel меньше типичного фото.
- Публичный bucket или бессрочные ссылки: отклонено, документ ребёнка не должен быть доступен по ссылке.
- Files API OpenAI: отклонено, создаёт второе хранилище документа вне проекта.
- Хранить полный OCR-текст: отклонено для MVP; проверка родителем идёт по оригиналу и цитатам.
- Не сохранять оригинал: отклонено, спецификация требует сохранить файл до разбора и показать его рядом с полями.

## Consequences
Положительные: оригинал доступен только владельцу; поздний ответ модели после сброса не восстанавливает данные; удаление повторяемо.
Издержки: реальные документы уходят внешнему провайдеру. Цитаты модели нельзя проверить автоматически. Разбор идёт внутри одного запроса (до 120 с).
Открыто: текст согласия и срок хранения не согласованы юридически; периодический сборщик очереди удаления (cron) не добавлен — очередь дочищается при следующем сбросе, удалении или загрузке; сканы плохого качества и многостраничные PDF не измерялись.

## Superseded when
- Принято юридическое решение о реальных данных или требование хранить и обрабатывать документы внутри страны.
- Появляется распознавание документов на собственной инфраструктуре.
