## Назначение
Эталон формулировок десяти вопросов для родителя. Источник: сообщение пользователя от 30.09.2026. При изменении UI сравнивать текст и варианты с этой таблицей. Реализация: @src/lib/interview.ts, @src/app/parent/interview/interview.tsx.

| № | Вопрос родителю | Варианты / ввод | Зачем нужен |
|---|---|---|---|
| 1 | Сколько лет ребёнку? | Полные годы, от 0 до 17 | Определяет возрастную ветку: до 3 лет / 3–14 / 14–18 |
| 2 | Где ребёнок фактически проживает? | Город, район | Поиск доступных служб и ближайших центров |
| 3 | Где ребёнок зарегистрирован по месту жительства? | Совпадает / другой адрес (город и район) | Для услуг, привязанных к территории, прежде всего ПМПК |
| 4 | Какие этапы вы уже проходили? | Несколько: консультации специалистов / ПМПК / оформление инвалидности / реабилитационный центр / ничего из перечисленного | Понимаем текущую точку маршрута и не заставляем проходить путь заново |
| 5 | Есть ли действующее заключение ПМПК? | Да / нет / в процессе / не знаю | Если нет — строим шаг прохождения ПМПК; если есть — используем существующий этап |
| 6 | Оформлена ли ребёнку инвалидность? | Да / нет / оформляем сейчас / не планируем | Определяет социальную ветку и возможные услуги |
| 7 | Какой вариант помощи вы рассматриваете? | Государственный / частный за свой счёт / сочетание обоих / пока не знаю | Не всем родителям нужен государственный маршрут |
| 8 | Получает ли ребёнок сейчас помощь или реабилитацию? | Нет / да, в государственном центре / да, в частном центре / другое | Проверяем, есть ли уже действующий маршрут |
| 9 | Какие услуги ребёнок уже получает сейчас? | Выбор только из справочника услуг | Сопоставляем текущее состояние с доступными услугами и исключаем дублирование |
| 10 | Что вам сейчас важнее всего? | Понять, с чего начать / оформить документы / пройти ПМПК / найти центр / разобраться с доступными услугами / продолжить текущий маршрут / проверить, что ничего не упускаем | Помогает объяснить и приоритизировать Case Plan |

## Примечания к реализации
- Вопросы идут последовательно, по одному на экран. Сохранение каждого ответа и прогресса — в @supabase/migrations/0002_interview_sessions.sql.
- Справочник услуг для вопроса 9 пока локальный список в @src/lib/interview.ts. Он служит только допустимыми вариантами ответа; права на услуги по нему не определяются.
- Для вопроса 3 «другой адрес» в MVP означает другой город или район; точный адрес не собирается.
- Возрастные диапазоны в исходной формулировке пересекаются на 14 годах. В коде граница для дальнейшей маршрутизации ещё не используется.
